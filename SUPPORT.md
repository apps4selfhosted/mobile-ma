# Support

## Before you open an issue

Most connection problems are covered in the [FAQ](https://www.mobile-ma.app/en/faq/).
If your players behave oddly, check whether the same happens in the Music Assistant web UI —
if it does, the [Music Assistant support repository](https://github.com/music-assistant/support)
is the better place.

## Ways to reach me

| | |
|---|---|
| Bug report | [Open an issue](https://github.com/apps4selfhosted/mobile-ma/issues/new?template=bug_report.yml) |
| Feature request | [Open an issue](https://github.com/apps4selfhosted/mobile-ma/issues/new?template=feature_request.yml) |
| Private request | [Support form](https://www.mobile-ma.app/en/support/) |

Replies usually within one to two days. Issues here are read and triaged by hand; development
itself happens in a private tracker, so an issue may be closed with a note naming the version
that fixes it rather than a commit link.

## Please do not post

Server URLs, access tokens, passwords or anything else that would let a stranger reach your
Music Assistant instance. The diagnostics export (Settings → Diagnostics, from version 3.5)
is designed to be safe to share, but do give it a read before attaching it.
